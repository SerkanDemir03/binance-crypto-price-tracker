# Binance Crypto Price Tracker - Frontend

React frontend application for Binance cryptocurrency price tracking with real-time charts.

## 🚀 Features

- Dashboard with cryptocurrency cards
- Real-time price updates
- Interactive price history charts
- 24-hour statistics
- Responsive design
- Auto-refresh functionality

## 📦 Installation

```bash
npm install
```

## ⚙️ Configuration

Create `.env` file:

```env
VITE_API_URL=http://localhost:5000/api
```

## 🏃 Running

```bash
# Development
npm run dev

# Build
npm run build

# Preview production build
npm run preview
```

## 🛠️ Tech Stack

- React 18
- Vite
- React Router v6
- React Query
- Recharts
- Tailwind CSS
- Axios
- React Hot Toast
- Lucide React Icons

## 📱 Pages

- `/` - Dashboard with all cryptocurrency cards
- `/crypto/:symbol` - Detailed view with charts and statistics
